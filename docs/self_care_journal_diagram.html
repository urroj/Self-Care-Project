PROXY NOTE
All /api/* requests go through the Vite dev-server proxy (port 5173 → 8000) in dev mode, or are served directly by FastAPI in production. The browser never contacts Yahoo Finance — FastAPI is the sole proxy for ETF data to avoid CORS.
